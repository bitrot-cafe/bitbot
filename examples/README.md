# Examples

**Not part of the bot.** Nothing in here is loaded by default or included in the image.

- `plugins/whoami/` is a complete example plugin to copy from. The live copy is in
  [bitbot-plugins](https://github.com/bitrot-cafe/bitbot-plugins); install that repo with
  `!root plugins add https://github.com/bitrot-cafe/bitbot-plugins`.

To try an example locally, copy its folder to `plugins/local/<name>` (git-ignored) and
`!root plugins enable local/<name>`; it loads without a restart.
